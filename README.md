# Ecoa — app

**Juntos, a gente ecoa.** Interação ao vivo da LTI: o apresentador projeta uma pergunta e a sala responde pelo celular.

- **Participar** (sem login, com o PIN da tela): https://micaiaspaiva-lti.github.io/ecoa-app/
- **Apresentar** (conta Google **@lti.net.br**): https://micaiaspaiva-lti.github.io/ecoa-app/apresentar/

Este repositório contém **apenas** a casca instalável (PWA) que abre o Web App do Google Apps Script em tela cheia. O sistema, os dados e as regras de acesso ficam no Google. O código-fonte está em um repositório privado.

## Instalar como app

- **Chrome / Edge (computador):** abra o link e clique no ícone de instalar na barra de endereço.
- **Android (Chrome):** menu ⋮ → *Instalar app*.
- **iPhone (Safari):** Compartilhar → *Adicionar à Tela de Início*.
